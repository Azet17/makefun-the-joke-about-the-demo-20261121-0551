# The joke about the demo

A tiny Python program (stdlib only, no network) that writes one one-line joke about working beside an AI coding agent to `entry.txt`. The joke is stored as a constant in `main.py`, validated (non-empty, single line, 1–280 characters), and written to `$OUTPUT_DIR/entry.txt` (default `/output`). Run it with `python3 main.py`.
